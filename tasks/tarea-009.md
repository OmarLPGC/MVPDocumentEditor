# Tarea 009: Crear la ventana principal y el entorno de edición

## Objetivo
Construir la interfaz mínima de la aplicación para abrir un documento nuevo, interactuar con el contenido y preparar la capa de edición visual.

## Subtareas
- Crear la ventana principal de la aplicación.
- Diseñar un layout base con área de trabajo y barras de herramientas.
- Integrar el modelo de documento con la vista editable.
- Habilitar la ejecución en modo de prueba para automatización.

## Tareas a realizar
1. Implementar la estructura visual principal.
2. Definir la zona de edición y la toolbar básica.
3. Conectar la vista con la lógica del documento.
4. Preparar modo de prueba para simular interacción.

## Criterios de aceptación
- La aplicación se abre correctamente.
- El documento nuevo está listo para editar.
- La vista se integra con la lógica del documento.

## Pruebas de aceptación
- Ejecutar la app en modo normal y en modo test.
- Verificar que la ventana principal se crea sin errores.
- Simular la apertura de un documento nuevo y comprobar que no falla.
