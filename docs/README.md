# Documentación del proyecto

Este directorio recoge la documentación técnica y de uso del editor de texto.

## Estructura prevista

- `src/` contiene la lógica del producto por capas.
- `tests/` agrupa pruebas unitarias, de integración y de seguridad.
- `specs/` mantiene los requisitos funcionales y de seguridad.
- `tasks/` recoge el plan de trabajo desglosado por tareas.

La separación se mantiene para favorecer la testabilidad, la seguridad y la evolución incremental del editor.
